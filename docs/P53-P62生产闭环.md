# P53-P62 生产闭环

## 能力范围

- P53：Milvus HNSW ANN、OpenSearch BM25、RRF 融合，生产禁用 MySQL 向量扫描。
- P54：文档切片工件按 Embedding 分片拆分，每个 Worker 只加载当前分片和所需父分片。
- P55：生产租户资源强制 `X-Workspace-Id`，成员关系校验，前端统一透传活动空间。
- P56：Runtime SSE 事件写入 Redis 有界缓冲，支持 `Last-Event-ID` 断线续传。
- P57：首 Token 延迟入库，OTLP Trace 导出，保留 Prometheus SLO 指标。
- P58：主动检查 MinIO 与 OpenSearch，并通过 Kafka 执行幂等修复。
- P59：动态护栏规则、间接提示词注入检查、Unicode 归一化和 HTTP SSRF 防护。
- P60：Agent、Prompt、工作流发布门禁与限时审批豁免。
- P61：MySQL 备份、校验、隔离恢复、冒烟查询和 RTO 测量脚本。
- P62：GHCR 镜像、SBOM、漏洞扫描、Cosign 镜像签名和 GitHub 构建来源证明。

## 关键生产开关

```text
OAF_REQUIRE_WORKSPACE_CONTEXT=true
OAF_ALLOW_MYSQL_VECTOR_FALLBACK=false
OAF_ALLOW_LOCAL_EMBEDDING_FALLBACK=false
OAF_OTLP_TRACES_ENDPOINT=http://otel-collector:4318/v1/traces
```

Runtime 恢复接口为 `GET /api/runs/{runId}/events/stream?after={sequence}`。浏览器也可以发送 `Last-Event-ID` 请求头。
