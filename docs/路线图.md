# 路线图

## 已完成

- 登录、JWT、Redis Token 状态。
- 模型供应商 CRUD 和 OpenAI-compatible 聊天/SSE。
- Agent CRUD、发布、复制、删除、运行和资源级权限。
- RAG 知识库、上传、解析、切片、Embedding、Milvus 写入、检索和引用来源。
- REST API、Webhook、数据库查询、MCP 工具调用。
- LLM、RAG、Tool、Workflow、Evaluation 统一 Trace。
- 可视化工作流设计器和执行引擎。
- MCP Server 管理、发现、同步、测试和调用。
- 评测集、样本导入、批量 Agent 运行、指标、报告和 Trace 关联。
- Docker Compose、CI、开源文档、License、Issue/PR 模板。
- Agent 历史会话、消息持久化、继续对话和调试台历史面板。
- 成本与用量中心，包含 Token、成本、配额、导出和历史成本重算。
- 组织、工作空间、成员和资源归属治理。
- 异步任务中心，统一任务队列、进度、日志、取消和重试，知识库文档处理已接入。
- 审计与风险治理中心，包含操作审计采集、风险事件归集、高风险确认审批和处置闭环。
- 生产部署加固，包含 prod Profile、Secret 校验、安全响应头、生产 Compose、非 root 容器和部署文档。
- Prompt 模板中心与版本治理，包含 Prompt 模板 CRUD、变量解析、版本发布、复制、回滚和 Agent 绑定。

## 下一步

- 通知中心与消息触达已按当前优先级调整为后置能力。
- LLM-as-Judge 评测。
- 多 Agent 协作。
- 更多任务类型接入异步任务中心：评测批跑、MCP 发现、数据导入、向量重建。

## P15 模型网关与模型治理

- 已完成模型路由策略、候选模型、模型健康、失败回退和最近调用治理能力。
- Agent 调试对话与工作流 LLM 节点已接入模型网关，未显式指定模型时按场景策略路由。
- LLM 调用日志已记录路由策略、场景类型、决策快照和是否回退。
- 前端已新增“模型网关”页面，用于策略 CRUD、候选模型维护、健康指标和调用审计查看。
- 下一步可继续增强组织/空间级模型策略、模型灰度、熔断告警和多供应商成本优化。
