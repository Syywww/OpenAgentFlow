# 知识库治理

## 能力范围

- 治理概览：统计知识库、文档、分片、向量、解析失败、处理中、Milvus 同步异常、打开问题和高风险问题。
- 质量评分：按知识库计算文档数、分片数、向量数、失败文档数、向量异常数、Agent 绑定数和质量分。
- 治理扫描：自动发现解析失败、处理卡住、长期未更新、缺少向量、Milvus 同步异常、切片 Token 异常、未绑定智能体、空知识库。
- 问题处理：支持将治理问题标记为已解决或已忽略，并记录处理人、处理时间和备注。
- 策略管理：支持全局策略和指定知识库策略，配置陈旧天数、分片 Token 阈值、是否要求 Agent 绑定、是否要求 Milvus 同步、是否自动生成问题。

## 后端接口

- `GET /knowledge-governance/overview`：知识库治理概览。
- `GET /knowledge-governance/quality`：知识库质量列表。
- `POST /knowledge-governance/scan`：执行治理扫描并生成问题。
- `GET /knowledge-governance/issues`：查询治理问题。
- `POST /knowledge-governance/issues/{id}/handle`：处理治理问题。
- `GET /knowledge-governance/policies`：查询治理策略。
- `POST /knowledge-governance/policies`：创建治理策略。
- `PUT /knowledge-governance/policies/{id}`：更新治理策略。
- `DELETE /knowledge-governance/policies/{id}`：删除治理策略。
