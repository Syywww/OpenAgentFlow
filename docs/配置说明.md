# 配置说明

后端通过环境变量读取配置，未设置时使用本地开发默认值。

| 变量 | 说明 | 默认值 |
| --- | --- | --- |
| `OAF_MYSQL_URL` | MySQL JDBC 地址 | 本地 `openagentflow` 数据库 |
| `OAF_MYSQL_USERNAME` | MySQL 用户名 | `root` |
| `OAF_MYSQL_PASSWORD` | MySQL 密码 | `123456` |
| `OAF_REDIS_HOST` | Redis 地址 | `localhost` |
| `OAF_REDIS_PORT` | Redis 端口 | `6379` |
| `OAF_MILVUS_HOST` | Milvus 地址 | `localhost` |
| `OAF_MILVUS_PORT` | Milvus 端口 | `19530` |
| `OAF_JWT_SECRET` | JWT 签名密钥 | 本地开发占位密钥 |
| `OAF_JWT_EXPIRE_MINUTES` | JWT 有效期分钟数 | `1440` |
| `VITE_API_BASE_URL` | 前端接口基础地址 | `http://localhost:8080/api` |

## 模型 API Key

不要把真实模型 API Key 提交到 GitHub。

SQL 种子脚本只初始化模型供应商和模型接入点，不保存真实 API Key。真实 Key 请在系统设置页配置，或仅保存到本地数据库中。

## MySQL 初始化

Docker Compose 的 MySQL 服务会挂载：

```text
openagentflow-sql/mysql -> /docker-entrypoint-initdb.d
```

首次创建数据库时，MySQL 会自动执行 `V001` 到 `V009` 初始化脚本。

## 生产环境建议

- 使用强随机值覆盖 `OAF_JWT_SECRET`。
- 使用独立数据库账号替代 `root`。
- 为 MySQL、Redis、Milvus 配置持久化备份。
- 不要把 `.env` 提交到仓库。
