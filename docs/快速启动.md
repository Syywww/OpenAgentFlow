# 快速启动

本文档说明如何在本地或 Docker Compose 环境中启动 OpenAgentFlow-Java。

## 方式一：Docker Compose 启动

```powershell
cd E:\xm\OpenAgentFlow-Java\dm
Copy-Item .env.example .env
docker compose up -d --build
```

启动后访问：

- 前端：http://localhost:5173
- 后端：http://localhost:8080/api
- Swagger：http://localhost:8080/api/swagger-ui.html

默认账号：

```text
admin / 123456
```

## 方式二：本地开发启动

本地开发依赖：

- JDK 21
- Maven 3.9+
- Node.js 22+
- MySQL 8+
- Redis 7+
- Milvus 2.4+

启动前后端：

```powershell
cd E:\xm\OpenAgentFlow-Java\dm
.\scripts\start-dev.ps1
```

构建校验：

```powershell
cd E:\xm\OpenAgentFlow-Java\dm
.\scripts\build-all.ps1
```

停止本地开发服务：

```powershell
.\scripts\stop-dev.ps1
```

## 常见问题

- 如果后端编译失败，请确认当前终端使用的是 JDK 21。
- 如果前端接口请求失败，请确认 `VITE_API_BASE_URL` 指向 `http://localhost:8080/api`。
- 如果 Docker Compose 首次启动较慢，通常是 MySQL 初始化 SQL 和 Milvus 首次启动需要等待。
