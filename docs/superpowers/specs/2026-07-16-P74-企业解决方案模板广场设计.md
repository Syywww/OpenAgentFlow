# P74 企业解决方案模板广场设计

## 目标

把现有静态模板广场升级为免费、可运营、可治理、可交付的企业解决方案模板市场。模板可包含多个 Agent、Agent 团队、Prompt、工具、知识库、文档、切片、向量、工作流和 Memory 配置；安装后所有资源均成为目标工作空间的独立副本。

## 产品边界

- 模板分为系统公开模板和工作空间私有模板。
- 私有模板提交公开广场前，必须通过自动检查和管理员人工审核。
- 模板只支持免费使用，不建设支付、订单、授权收费和收益结算。
- 公开版本采用语义化版本，版本不可变，必须提供更新说明和兼容性声明。
- 安装端只提示升级，不自动升级，不允许作者强制推送。

## 模板包模型

- 发布者选择一个或多个入口 Agent 或 Agent 团队。
- 系统自动分析 Prompt、工具、知识库、工作流、Memory 和 MCP 依赖，发布者可手动增删。
- 模板版本保存资源清单、资源快照、依赖图、内容哈希、对象清单、兼容性声明和安全检查结果。
- 知识库文档、向量快照和大文件存入 MinIO；MySQL 只保存对象地址、大小、哈希和清单。
- API Key、认证头、MCP 环境密钥和外部工具凭证不进入模板快照。

## 发布治理

- 草稿可编辑，提交后执行敏感信息、Prompt 注入、工具风险、依赖完整性、许可证和最小可运行检查。
- 自动检查未通过时阻止进入人工审核。
- 管理员可批准、驳回或要求修改；审批结果和理由入库。
- 已批准版本可上架、下架和推荐，公开版本不可直接修改，只能发布新版本。
- 举报进入治理队列，管理员可处理并下架高风险模板。

## 安装流程

- 安装向导选择目标工作空间、资源名称前缀、模型替代映射、Embedding 模型和外部凭证补充状态。
- 创建 `template_install` 异步任务，经 Transactional Outbox 投递 Kafka。
- Worker 按 Prompt、工具、知识库、文档、切片、向量、工作流、Agent、团队、Memory 顺序复制。
- 每项复制写入安装资源映射、来源哈希和安装哈希，页面展示阶段与百分比。
- 文档对象复制到目标工作空间专属 MinIO 路径；兼容向量批量写入 Milvus，不兼容时保留文档与切片并创建重新向量化待办。
- 模型或凭证缺失时允许安装完成，但关联 Agent 保持草稿且不可启用。
- 任一步失败时按资源映射逆序补偿，删除本次创建的数据库资源、对象和向量。

## 升级与卸载

- 新版本发布后，已安装实例显示可升级标识和版本差异。
- 升级使用旧模板版本、本地安装资源、新模板版本三方对比。
- 无冲突资源可自动更新；冲突资源由用户逐项选择保留本地或采用新版。
- 用户新增的知识文档始终保留，模板原有文档按三方差异更新。
- 默认卸载只解除模板关系并保留资源。
- 可选删除未修改的模板资源；已修改资源和用户新增数据永不自动删除。

## 运营能力

- 公开广场支持分类、标签、关键词、推荐、最新、热门和趋势排行。
- 只有成功安装过模板的用户可以评分评论，每个用户每个模板只有一条评价，可修改。
- 作者和管理员可以回复评论，但不能修改用户原文。
- 支持收藏、安装量、评分、评论、举报、作者主页和版本更新通知。
- 管理台展示安装成功率、失败原因、趋势、待审核、举报和风险分布。

## 接口与权限

- `/templates` 提供公开列表、详情、版本、收藏、评价、举报和作者信息。
- `/templates/manage` 提供工作空间模板 CRUD、依赖分析、发布、提交审核和版本管理。
- `/templates/reviews` 提供管理员审核、推荐和上下架。
- `/templates/{id}/install` 创建异步安装，`/template-installs` 提供进度、升级、冲突决策和卸载。
- `template:view` 可浏览，`template:publish` 可发布私有模板，`template:review` 可审核公开模板，`template:operate` 可运营推荐与举报。

## 可靠性与安全

- 安装请求使用幂等键，重复提交返回同一安装任务。
- 资源复制采用阶段检查点，可由 Kafka 重试恢复，不重复创建资源。
- 所有对象和快照使用 SHA-256 校验。
- 工作空间权限在请求线程和 Worker 恢复后都执行检查。
- 所有对象字段和主要代码包含中文注释，所有表与字段包含中文注释。

## 测试

- 单元测试覆盖语义化版本、敏感配置清洗、依赖图、三方冲突和卸载保护。
- 服务测试覆盖审核状态机、安装幂等、评论资格和升级可用性。
- 数据库迁移检查新增表、字段和中文注释。
- 前端类型检查、单测和生产构建覆盖筛选、安装向导和进度状态。
