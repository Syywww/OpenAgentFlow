# 调试台自动定位最新消息实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 历史会话消息加载完成后，调试台对话容器自动定位到最后一条消息。

**Architecture:** 使用独立滚动工具封装容器底部定位，`DebugWorkbenchView.vue` 在 `nextTick()` 后调用。保留消息正常 DOM 顺序，只操作对话容器自身的 `scrollTop`。

**Tech Stack:** Vue 3、TypeScript、Vitest、Vite

## Global Constraints

- 不改变现有调试台布局和样式。
- 仅在历史会话存在消息时自动定位。
- README 不加入测试过程内容。

**Interfaces:**
- Consumes: 带有 `scrollTop` 和 `scrollHeight` 的消息容器。
- Produces: `scrollToLatest(container)`，将容器定位到底部。

- [ ] **Step 1: 编写失败单元测试**

```ts
import { describe, expect, it } from 'vitest';
import { scrollToLatest } from './chatScroll';

describe('scrollToLatest', () => {
  it('将消息容器定位到内容底部', () => {
    const container = { scrollTop: 0, scrollHeight: 1280 };
    scrollToLatest(container);
    expect(container.scrollTop).toBe(1280);
  });
});
```

- [ ] **Step 2: 执行测试并确认因模块缺失而失败**

Run: `npm run test:unit -- src/utils/chatScroll.test.ts`

Expected: FAIL，提示无法解析 `./chatScroll`。

- [ ] **Step 3: 实现滚动工具并接入调试台**

```ts
export interface ScrollContainer {
  scrollTop: number;
  readonly scrollHeight: number;
}

export function scrollToLatest(container: ScrollContainer | null | undefined) {
  if (container) container.scrollTop = container.scrollHeight;
}
```

在调试台中绑定 `chatMessagesRef`，`openSession()` 映射消息后等待 `nextTick()`，有消息时调用 `scrollToLatest(chatMessagesRef.value)`。
