> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 完成内置解决方案模板、工作流高级执行与 MCP 多传输中所有 P0 缺口。

**Architecture:** 复用现有模板资源拓扑复制、Kafka Outbox、Runtime Trace 和评测服务；通过小型策略类隔离并行合并、灰度选版、插件注册及 MCP 传输。所有外部入口保持兼容。

**Tech Stack:** Java 21、Spring Boot、MyBatis-Plus、MySQL 8、Kafka、Redis、JUnit 5、JDK HttpClient。

- 不自动重启后端；完成后只执行编译、测试和迁移检查。
