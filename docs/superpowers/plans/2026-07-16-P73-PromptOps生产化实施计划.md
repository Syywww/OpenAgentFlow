# P73 PromptOps生产化实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将现有 Prompt 模板 CRUD 升级为支持版本绑定、统一编译、实验灰度、质量门禁、运行观测和多环境晋级的生产级 PromptOps。

**Architecture:** MySQL 保存不可变版本、资源绑定、环境发布、实验变体和运行指标；`PromptRuntimeService` 负责版本解析、变量 Schema 校验、分层组合、渲染和 Token 估算。Agent、工作流与评测运行统一调用该服务，Trace 保存实际版本、变量来源和装配层；Prompt 中心增加预览、影响分析、版本差异、实验与指标四类工作面板。

**Tech Stack:** Java 21、Spring Boot 3.3、MyBatis-Plus、MySQL 8、Vue 3、TypeScript、Vitest、Flyway

## Global Constraints

- Java 新增类、方法、主要代码块和对象字段使用中文注释。
- 不自动启动或重启后端。
- 保持现有 Prompt 页面视觉体系和卡片切换结构。
- SQL 主目录与 Flyway 运行时副本保持一致。
- 每次项目修改同步更新 `README.md`，且 README 不加入测试过程内容。
