# P76 可重复构建与质量门禁实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立不依赖开发者本机服务状态的后端测试环境，并扩充登录与权限菜单浏览器测试。

**Architecture:** 通过 Spring `test` Profile关闭外部副作用，使用共享 MySQL Testcontainers 基类提供真实 Flyway 数据；Playwright 通过确定性接口响应覆盖完整前端认证状态流转。CI 必须具备 Docker，否则后端门禁立即失败。

**Tech Stack:** Java 21、Spring Boot Test、JUnit 5、Testcontainers、MySQL 8、Flyway、Vue 3、Playwright、GitHub Actions。

## Global Constraints

- 后端新增类、字段、方法和主要逻辑必须包含中文注释。
- 不启动或重启用户在 IDEA 中运行的后端进程。
- 不访问真实模型、Embedding、Milvus和外部通知服务。
- 每次项目修改同步更新根 README。
