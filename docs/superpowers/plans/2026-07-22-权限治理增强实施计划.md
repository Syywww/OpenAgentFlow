# 权限治理增强实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 建立统一路由鉴权、工作空间角色、数据范围、通用 ACL、会话撤销和按钮权限组成的企业级权限治理体系。

**Architecture:** Spring Security 路由授权管理器负责第一层默认拒绝，工作空间过滤器与空间授权服务负责租户边界，资源 ACL 服务负责对象权限，原有 Service 规则继续作为业务防线。Redis 用户令牌索引支持权限变化后的立即下线，前端通过统一权限指令控制操作入口。

**Tech Stack:** Java 21、Spring Boot 3、Spring Security 6、MyBatis-Plus、JdbcTemplate、MySQL 8、Redis、Vue 3、TypeScript、Vitest。

## Global Constraints

- Java 新增类、方法、主要逻辑和对象字段必须包含中文注释。
- SQL 表和字段必须包含中文注释，并同步到 SQL 主目录和 Flyway 目录。
- 不自动启动后端服务。
- 每次项目变更同步更新 README，但不加入过程性运行流水。
