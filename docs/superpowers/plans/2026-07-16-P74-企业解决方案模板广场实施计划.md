# P74 企业解决方案模板广场实施计划

> **For agentic workers:** REQUIRED SUB-SKILL: Use superpowers:subagent-driven-development (recommended) or superpowers:executing-plans to implement this plan task-by-task. Steps use checkbox (`- [ ]`) syntax for tracking.

**Goal:** 将静态模板页面升级为支持解决方案包发布、审核、异步完整安装、三方升级、运营治理的企业模板市场。

**Architecture:** 使用不可变模板版本清单描述解决方案资源，以资源哈希和安装映射支撑幂等复制、补偿、三方升级和安全卸载。安装任务复用 Kafka、Transactional Outbox、MinIO、Milvus 和现有异步任务中心。

**Tech Stack:** Java 21、Spring Boot 3、MyBatis-Plus/JdbcTemplate、MySQL 8、Kafka、MinIO、Milvus、Vue 3、TypeScript、Vite。

## Global Constraints

- 后端代码、对象字段和主要处理逻辑使用中文注释。
- SQL 新增表和字段全部使用中文注释。
- 后端修改后不自动启动。
- 每次项目修改同步更新 `dm/README.md`，且 README 不写执行过程明细。
- 前端延续现有管理台风格和原型页面结构。
