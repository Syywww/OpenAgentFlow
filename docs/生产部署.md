# 生产部署加固

本文档用于生产环境部署 OpenAgentFlow-Java。生产部署建议使用 `docker-compose.prod.yml`，并通过 `.env.prod` 管理密钥、域名和资源限制。

## 部署前检查

1. 复制生产环境变量模板：

```powershell
cd E:\xm\OpenAgentFlow-Java\dm
Copy-Item .env.prod.example .env.prod
```

2. 修改 `.env.prod`，替换所有 `CHANGE_ME`：

- `OAF_MYSQL_PASSWORD`：业务库强密码。
- `OAF_MYSQL_ROOT_PASSWORD`：MySQL root 强密码。
- `OAF_REDIS_PASSWORD`：Redis 强密码。
- `OAF_MINIO_ROOT_PASSWORD`：MinIO 强密码。
- `OAF_JWT_SECRET`：不少于 32 位的随机字符串。
- `OAF_CORS_ALLOWED_ORIGINS`：生产前端域名，例如 `https://ai.example.com`。

3. 确认生产域名、HTTPS、反向代理和防火墙：

- 对外只暴露前端网关端口，默认 `OAF_HTTP_PORT=80`。
- MySQL、Redis、Milvus、MinIO、etcd 不在宿主机公开端口。
- 建议在云负载均衡、Nginx、Traefik 或网关层启用 HTTPS。

## 启动

```powershell
cd E:\xm\OpenAgentFlow-Java\dm
.\scripts\prod-up.ps1 -Build
```

停止：

```powershell
.\scripts\prod-down.ps1
```

查看服务：

```powershell
docker compose --env-file .env.prod -f docker-compose.prod.yml ps
```

查看后端日志：

```powershell
docker logs -f openagentflow-backend-prod
```

## 后端加固

- 生产容器启用 `SPRING_PROFILES_ACTIVE=prod`。
- 生产启动会校验 JWT Secret、CORS 来源和 MySQL 密码；使用默认值会直接启动失败。
- Actuator 生产只暴露 `health`、`info`、`prometheus`，健康详情不对外展示。
- Swagger 默认关闭，如确需临时开启，设置 `OAF_SWAGGER_ENABLED=true`，使用后应关闭。
- CORS 由 `OAF_CORS_ALLOWED_ORIGINS` 控制，生产禁止使用 localhost 或通配来源。
- 后端容器使用非 root 用户运行，并配置 JVM 内存比例和 OOM 退出策略。
- 文件上传数据落到 `backend-data` 卷，避免容器重建丢失本地上传文件。

## 前端与网关加固

- 前端使用非特权 Nginx 镜像运行，容器内监听 `8080`。
- Nginx 已配置安全响应头：
  - `X-Content-Type-Options`
  - `X-Frame-Options`
  - `Referrer-Policy`
  - `Permissions-Policy`
  - `Content-Security-Policy`
- 静态资源启用长期缓存，`/api/` 反向代理到后端。
- SSE 和长耗时接口已关闭代理缓冲，并提高读写超时时间。

## 数据与备份

建议至少备份以下 Docker volumes：

- `mysql-data`：业务数据、权限、配置、Trace、审计。
- `redis-data`：Redis 持久化数据。
- `milvus-data`：Milvus 向量数据。
- `minio-data`：Milvus 对象存储数据。
- `etcd-data`：Milvus 元数据。
- `backend-data`：本地上传文件。

MySQL 示例备份：

```powershell
docker exec openagentflow-mysql-prod mysqldump -uroot -p openagentflow > openagentflow-backup.sql
```

## 发布建议

- 每次发布前执行后端编译和前端构建：

```powershell
.\scripts\build-all.ps1
```

- 生产镜像建议使用固定 tag，例如：

```text
OAF_IMAGE_TAG=2026.06.23
```

- 发布前检查 `.env.prod` 不包含 `CHANGE_ME`、默认密码或默认 JWT Secret。
- 发布后访问 `/api/actuator/health` 检查后端健康状态。
- 进入“风险治理”页面确认审计日志正常写入。
